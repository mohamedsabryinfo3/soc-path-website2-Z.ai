# مسار SOC — من الشبكات إلى الأمن السيبراني 🔐

موقع تفاعلي احترافي لبناء **مسار SOC Analyst** من الصفر، مبني على تحليل محتوى **306 فيديو** من 5 قوائم يوتيوب (عبير حسني وأحمد نظمي) — مع تصنيف بالأولويات ومقارنة أفضل الشروحات وخطوة بخطوة حتى يوم المحلل الفعلي.

> كل فيديو فُحص على مستوى **المحتوى لا العنوان**: عمق الشرح، التطبيق العملي، الأمثلة — ثم اختُبر الأقوى شرحًا مع توثيق سبب كل اختيار وكل استبعاد.

## ✨ الميزات

| القسم | الوصف |
|---|---|
| 🏠 **الرئيسية** | نظرة عامة + إحصائيات التحليل + "كمّل من حيث وقفت" |
| 🗺️ **المسار التسلسلي** | 8 مراحل / 51 درسًا مختارًا، مع سبب اختيار كل درس وعلاقته بـ SOC ومرجع بديل |
| 🎚️ **الأولويات** | كل الـ 306 فيديو مصنفة: مهم / متوسط / فيما بعد / غير مهم — مع فلترة وبحث فوري |
| 📚 **القوائم الخمس** | كل قائمة كاملة: المختار ✓ والبديل ★ والمستبعد — والأسباب |
| ⚖️ **المقارنات** | لكل موضوع متكرر: من فاز ولماذا (تحليل محتوى موثق) |
| 🚀 **ما بعد الكورسات** | المهارات التالية + خارطة الشهادات + نصائح التوظيف + قاموس 24 مصطلحًا |

**تفاعلية:** تتبع تقدم يُحفظ تلقائيًا في المتصفح (localStorage) + شريط إنجاز لكل مرحلة + بحث وفلترة + واجهة عربية RTL بثيم أزرق مؤسسي.

## 🗂️ بنية المشروع

```
src/
├── app/              # صفحة واحدة (App Router) + الثيم
├── components/soc/   # واجهات الأقسام الستة
├── data/             # قلب المشروع: بيانات التحليل
│   ├── playlists/    # القوائم الخمس مع تصنيف كل فيديو وسببه
│   ├── path.ts       # المسار التسلسلي (8 مراحل / 51 خطوة)
│   ├── comparisons.ts# المقارنات الموثقة
│   └── beyond.ts     # ما بعد الكورسات + القاموس
├── hooks/            # useMounted
└── lib/store.ts      # Zustand + حفظ التقدم
```

## ▶️ التشغيل محليًا


## 🚀 النشر على Vercel (الطريقة الأسهل)

1. ادخل [vercel.com](https://vercel.com) وسجّل بحساب GitHub.
2. **Add New → Project** ثم اختر مستودع `soc-path-website`.
3. اترك كل الإعدادات الافتراضية (Vercel يكتشف Next.js تلقائيًا) واضغط **Deploy**.
4. بعد دقيقة يكون موقعك على رابط مثل: `https://soc-path-website.vercel.app`

أو من الطرفية:

```bash
npm i -g vercel
vercel          # أول مرة: اربط الحساب ثم أكّد الافتراضيات
vercel --prod
```

> 💡 الموقع ثابت تمامًا (لا قاعدة بيانات ولا سيرفر) — كل التقدم محفوظ في متصفح الزائر نفسه، فلا يحتاج أي إعداد إضافي.

## 🧭 منهجية الخطة (خلاصة)

1. **تحليل المحتوى لا العنوان** — فحص عمق الشرح والتطبيق والأمثلة لكل درس.
2. **الأفضل شرحًا يفوز** — المقارنة بين النسخ المتشابهة من القوائم المختلفة.
3. **لا تكرار بلا مكمل** — درس ثانٍ يُضاف فقط إن قدّم جزءًا مكملًا واضحًا.
4. **كل قرار موثق** — سبب الاختيار والاستبعاد مكتوب جنب كل درس.
5. **القوائم مرجع دائم** — تحتفظ بكل القوائم للرجوع إليها عند أي شرح ثانٍ.
